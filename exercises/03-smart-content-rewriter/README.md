# Exercise 03: Smart Content Rewriter

## 🎯 Overview
A powerful Gradio application that transforms any text into 5 different styles simultaneously using GPT or Claude. Perfect for content creators, marketers, and anyone who needs to adapt their message for different platforms and audiences.

## ✨ Features

### 5 Rewrite Styles:
1. **📊 Professional** - Formal business tone with sophisticated vocabulary
2. **💬 Casual** - Friendly, conversational style
3. **🐦 Tweet Thread** - Twitter-optimized with character limits and emojis
4. **💼 LinkedIn Post** - Engagement-focused with hooks and CTAs
5. **📝 Summary** - Concise bullet-point key takeaways

### Additional Features:
- Choose between GPT-4o-mini or Claude-3-haiku
- Copy button for each version
- Tabbed interface for easy comparison
- Example content to get started
- Real-time generation progress
- Clean, modern UI

## 🎓 Learning Objectives

This exercise teaches:
- **Prompt Engineering**: Crafting specific style instructions
- **Multi-output Generation**: Creating multiple variations simultaneously
- **Gradio Tabs**: Organizing multiple outputs
- **Model Comparison**: Using different LLMs for the same task
- **User Experience**: Progressive output display
- **Error Handling**: Graceful failures with helpful messages
